# Data provenance

| File | Contents | Origin / license |
|------|----------|------------------|
| `catalysis_X.csv` | 91 x 59 primary-feature matrix (single-atom catalysis) | Senftle group `tsenftle/Metal-Oxide-LASSO-lo`, **MIT**. Numeric DFT facts. |
| `catalysis_y.csv` | 91 metal/oxide binding energies (eV) | same as above |
| `oracle_ibart.json` | Published iBART l0 best-k descriptors + RMSEs (citable facts) | Liu et al. 2022 / Ye et al. 2024; extracted from the GPL-3 R iBART package's `iBART_real_data` for validation only, trimmed to published facts, with attribution. See `../NOTICE.md`. |
